# AutoKosa Mod for Minecraft 1.21.11

Мод для автоматического удара косой жнеца (iron_hoe) после использования тотема бессмертия. Разработан для сервера Bloodstone.

## Функционал

- Автоматически отслеживает использование тотема бессмертия игроком
- После использования тотема наносит удар косой жнеца (4 HP урона = 2 сердца)
- Работает на серверах PvP (Bloodstone)
- Совместим с Minecraft 1.21.11 и Fabric Loader

## Как работает

1. Игрок умирает и использует тотем бессмертия
2. Мод перехватывает событие использования тотема
3. Сразу после тотема наносит 4 HP урона косой жнеца
4. Так как тотем уже использован, игрок умирает от этого удара

## Команды для тестирования

- `/autokosa info` - информация о моде
- `/autokosa test` - нанести себе урон косой
- `/autokosa test @p` - нанести урон ближайшему игроку

## Сборка через GitHub Actions

Этот мод настроен для автоматической сборки через GitHub Actions:

1. При любом изменении кода запускается автоматическая сборка
2. Используется Java 21 и Fabric Loom 1.18.4
3. Готовый .jar файл доступен в Artifacts

## Локальная сборка

```bash
./gradlew build
```

Требования: Java 21, Gradle 9.4+, Fabric Loom 1.18.4+

## Установка

1. Скачайте `auto-kosa-1.0.0.jar` из Artifacts GitHub Actions
2. Поместите в папку `%APPDATA%\.minecraft\mods`
3. Запустите Minecraft 1.21.11 с Fabric Loader
4. Присоединитесь к серверу Bloodstone

## Для разработчиков

Мод использует:
- Fabric API для Minecraft 1.21.11
- Mixins для перехвата события тотема
- Fabric Loader 0.19.5
- Java 21

## Как работает

1. Когда игрок использует тотем бессмертия (при смерти)
2. Мод перехватывает это событие
3. Сразу после использования тотема наносит 4 HP урона косой жнеца
4. Так как тотем уже использован, игрок умирает от этого удара

## Установка

### Для разработки:
1. Установите Java 21
2. Клонируйте проект
3. Запустите: `.\gradlew build`
4. Собранный мод будет в `build/libs/`

### Для использования:
1. Соберите мод с помощью gradle
2. Поместите файл `.jar` в папку `mods` клиента Fabric
3. Запустите Minecraft с Fabric Loader

## Технические детали

- Использует Fabric API и Mixins
- Перехватывает метод `checkTotemDeathProtection` у ServerPlayer
- Наносит урон типом `DamageTypes.PLAYER_ATTACK`

## Для сервера Bloodstone

Мод специально разработан для PvP на серверах типа Bloodstone, где коса жнеца (iron_hoe) используется для "добивания" игроков после тотема.
